# TreeCreator

フォルダ構造を画面またはインデント付きテキストで設計し、空フォルダだけを含むZIPとして出力するツールです。ブラウザ内で完結し、入力内容を外部へ送信しません。

## ブラウザで使う

**[TreeCreatorを開く](https://kanzennirikaisita.github.io/TreeCreator/)**

インストールせず、そのままブラウザで利用できます。

## 使い方

1. `index.html` をEdgeまたはChromeで開きます。
2. ルート名とフォルダ構造を編集します。
3. 必要に応じて採番、固定番号、JSON保存を使います。
4. 「ZIPで出力」を押し、検証結果を確認して保存します。

インストールやWebサーバは不要です。`file://` で直接動作します。

## 主な機能

- ツリー編集とインデント付きテキスト編集の双方向同期
- 空・最小・標準の3テンプレート
- 並び順から算出する2桁の自動採番と固定番号
- 追加、削除、並べ替え、字下げ、字上げ、折りたたみ
- Undo / Redo（最大50状態）
- Windows禁止文字、予約名、重複名、空名、パス長の検証
- 空ディレクトリエントリ方式のZIP出力（UTF-8、`.keep` 不使用）
- JSON保存・読込
- LocalStorageによる編集中データの復旧

## テキスト記法

半角空白2個またはTab 1個で階層を表します。固定番号は名前の末尾に `[99]` と書きます。

```text
資料
  受領
  作業用
検討
成果
参考 [99]
```

## キー操作

| キー | 操作 |
|---|---|
| `Enter` | 選択中フォルダの下に追加 |
| `Tab` / `Shift+Tab` | 字下げ / 字上げ |
| `Alt+↑` / `Alt+↓` | 同一階層内で移動 |
| `F2` | 名前変更 |
| `Delete` | 削除 |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |

## パス長について

出力前に、入力した基点パス長と生成する相対パスを合算します。240文字以上は警告、260文字以上はエラーです。警告は、フォルダ内へ後から保存するファイル名の余裕を確保するために表示します。

## 対応環境

現在のMicrosoft Edge、Google Chromeを対象としています。ZIP内の日本語名はUTF-8フラグを設定しています。実運用前に、組織で使用する展開ソフトで一度確認してください。

## セキュリティと配布

- 外部ライブラリ、CDN、通信処理は使用していません。
- ファイルサーバへ直接書き込みません。
- HTMLの配布経路によっては、メールやグループウェアの制限でスクリプトが除去される場合があります。配布前に組織の運用ルールを確認してください。
- File System Access APIは使っていません。ローカルHTMLを `file://` で開く運用と両立しないためです。
